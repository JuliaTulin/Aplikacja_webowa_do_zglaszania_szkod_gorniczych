# Mining Damage Reporting Web Application

Bachelor's thesis project developed as part of my Geoinformatics studies at AGH University of Science and Technology.

The project involved developing a web application for reporting mining-related damage, including an interactive GIS map, user authentication, submission forms and database integration.

**Technologies:** JavaScript, Node.js, Leaflet.js, QGIS.

## Key Features

- Interactive map displaying mining areas and seismic events.
- Georeferencing and digitization of mining area boundaries using QGIS.
- Visualization of seismic events with magnitude-based symbols and date filtering.
- Mining damage reporting forms and user authentication.
- Database integration for storing submitted reports and user information.
